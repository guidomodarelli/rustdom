# Sampler con el ELF hospedado seleccionado

Las 22 pruebas reales del sampler pasaron en ambos SDK usando el ELF4b52a84d del
artifact12604810857, distinto del f8 de la primera calificación publicada. Cada SDK
conserva 448 tareas funcionales cronometradas, 23 probes y los controles separados
de retención/liberación de Window y Document, además de errores Symbol/undefined.

Se preservan los logs y observaciones originales de esa ejecución adicional.
Los comandos iniciales no capturaron Git HEAD/status; no se inventa una identidad
limpia. Los bytes del sampler coinciden con el componente publicado en5d823f49;
esa coincidencia de fuentes no convierte al commit en un dato medido del proceso.
Los roots temporales autenticados y sus archivos constan en la evidencia del worker.

Son pruebas funcionales, no inferencia ni aceptación de rendimiento. Los datos
originales de la calificación anterior con ELFf8 siguen intactos y diferenciados.
