# Calificación funcional del contrato de contexto

Raw íntegros de los 32 workers positivos y 12 adversos del padre con
`replayEnvelope`, Node 22.12.0/24.14.1. Incluyen comandos, stdout/stderr,
inputs, sidecars, manifests, validación previa/posterior del paquete y parciales.
La fuente Git privada y el alcance se documentan en
`reports/validation/jsdom-block-pilot/envelope/20261026/`.

No son muestras del piloto científico. No se agrupan con épocas anteriores,
no se calcula aceptación de rendimiento y no se ejecutan operaciones del
candidato Rust. Los resultados de recursos, incluidas las primeras rondas no
claras, están preservados por separado. Nunca ejecutar scripts archivados.
