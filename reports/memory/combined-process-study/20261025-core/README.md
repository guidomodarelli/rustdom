# Recursos del núcleo prospectivo

El núcleo reduce nueve spans a una media por proceso y conserva16pares por cada
una de64comparaciones. Sus resultados y acumuladores son acotados y no quedan
en caches globales. Los factores se clonan antes de congelarse,evitando modificar
los módulos históricos. La preparación real usa el verificador actual,archivos
y subprocesses finitos,sin importar módulos de los paquetes DOM.

No crea Window/Document,callbacks,observers o referencias N-API. Sus pruebas
sintéticas no son nuevas mediciones de memoria ni rendimiento. Los probes DOM
finitos del paquete están en reports/memory/range-combined-packages/
20261025-assembly/. No se midió memoria pico ni se prueba ausencia universal
de fugas. El futuro sampler deberá conservar sus rondas/contadores completos.
