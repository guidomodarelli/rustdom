head ff07406d. Node 22.12.0 y 24.14.1 aprobaron seis ciclos cada uno sobre el
paquete a277 autenticado antes de cargarlo. Los doce endpoints finales observaron

snapshots de heap, memoria externa y RSS, más stderr incluido el warning Node22.

no se mezclan con f2 anterior. Son pruebas finitas: no miden memoria pico ni
prueban ausencia universal de fugas. Sin aceptación de rendimiento, captura
científica ni cambio Rust. Producción sigue híbrida.
