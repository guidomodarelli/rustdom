# Recursos del ensayo local del job mínimo

Cada SDK Linux, Node 22.12.0 y 24.14.1, ejecutó seis ciclos del paquete
reconstruido desde el tar autenticado. Los doce endpoints finales liberaron
Window, Document, rangos JS y wrappers nativos por separado, con dos estados
claros consecutivos y el baseline nativo comprobado. Se conservan todas las
trazas, estados retenidos, RSS, heap y memoria externa.

Son resultados del fixture local del CI; no se presentan como resultados de
GitHub Actions. Los snapshots finitos no prueban memoria pico ni ausencia
universal de fugas. No cambió Rust ni el runtime; no hay rendimiento aceptado.
Node 22 mantiene el warning de interoperabilidad con parse5 del runtime híbrido.
